Repositori ini berisi kode sumber untuk website portofolio interaktif **Inlim Ravijai Rumahorbo**, yang dibangun menggunakan framework **Streamlit** dan di-deploy ke **Streamlit Community Cloud**.

Aplikasi ini menonjolkan profil profesional di bidang **Meteorologi**, **Penginderaan Jauh (Remote Sensing)**, serta **Analisis Data & Business Intelligence**.

---

## 🌐 Demo Langsung

Kunjungi web portofolio aktif di:  
👉 **[inlim-portfolio.streamlit.app](https://share.streamlit.io)** *(ganti tautan ini dengan URL Streamlit Cloud aktif Anda)*

---

## 📂 Struktur Halaman Web

Website ini mencakup beberapa navigasi utama:
- **About:** Ringkasan latar belakang, visi ketahanan pangan/iklim, artikel analitik, dan kompetensi inti.
- **Experience:** Rekam jejak operasional di Stasiun Meteorologi Binaka (Koordinator Operasional, Weather Forecaster, Weather Observer).
- **Projects:** Portofolio terapan, termasuk proyek unggulan *Weather Analyst: Pulau Nias 2025 (End-to-End Analysis)*.
- **Education:** Riwayat akademis di STMKG (Sarjana Terapan Meteorologi) dan SMAN 4 Pematang Siantar.
- **Publications & Honors:** Publikasi riset estimasi curah hujan radar/satelit (CST & MCST) dan pencapaian Finalis AI DATATHON 2024.
- **Contact:** Formulir komunikasi langsung.

---

## 🛠️ Stack Teknologi

- **Framework Web:** [Streamlit](https://streamlit.io/)
- **Bahasa Pemrograman:** Python
- **Analisis & Manipulasi Data:** Pandas, NumPy
- **Visualisasi Data:** Plotly Express
- **Deployment:** GitHub & Streamlit Community Cloud
